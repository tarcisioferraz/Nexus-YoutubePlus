# Nexus YouTube+

**Nexus YouTube+** is an advanced open-source Google Chrome extension designed to enhance, personalize, and optimize your YouTube browsing experience. It offers deep interface adjustments, performance enhancements, productivity tools, and seamless platform integration.

## 🚀 Features / Características / Funcionalidades

### 🇺🇸 English (Features)
- 🎨 **Interface Customization:** Tools to adapt YouTube's layout, hide clutter, and customize your viewing appearance.

## 📦 Installation / Instalación / Instalação

### 🇺🇸 English
1. Download or clone this repository.
2. Extract the files if they are compressed.
3. Open `chrome://extensions` in Google Chrome.
4. Enable **Developer mode** in the top-right corner.
5. Click **Load unpacked**.
6. Select the folder containing the extension's `manifest.json` file.

### 🇪🇸 Español
1. Descarga o clona este repositorio.
2. Extrae los archivos si están comprimidos.
3. Abre `chrome://extensions` en Google Chrome.
4. Activa el **Modo de desarrollador** en la esquina superior derecha.
5. Haz clic en **Cargar descomprimida** (*Load unpacked*).
6. Selecciona la carpeta que contiene el archivo `manifest.json` de la extensión.

### 🇧🇷 Português
1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Abra `chrome://extensions` no Google Chrome.
4. Ative o **Modo do desenvolvedor** no canto superior direito.
5. Clique em **Carregar sem compactação** (*Load unpacked*).
6. Selecione a pasta que contém o arquivo `manifest.json` da extensão.
